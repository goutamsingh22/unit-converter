# Unit Converter

A Python Tkinter application to convert between different units of measurement.

## Features

- Convert Temperature (Celsius, Fahrenheit, Kelvin)
- Convert Distance (Meters, Kilometers, Miles, Feet, Inches)
- Convert Weight (Grams, Kilograms, Pounds, Ounces)
- Convert Time (Seconds, Minutes, Hours, Days)
- Clean and intuitive GUI

## Requirements

- Python 3.x
- Tkinter (usually comes with Python)

## How to Run







```bash
python converter.py
```
